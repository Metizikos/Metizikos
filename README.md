### Featured Project

**🎙️ Real-Time C++ Voice Activity Detection (VAD) Pipeline** (2026)

A DSP tool that tells human speech from background noise in real time, similar to the smart-microphone logic in Discord and Zoom.

- Processes audio in 20 ms chunks and computes **Short-Time Energy** and **Zero-Crossing Rate (ZCR)**
- **Adaptive threshold** that adjusts to ambient noise levels
- Modular design built around a **Ring Buffer** and a **State Machine**
- **Zero dynamic allocation**: all memory is pre-allocated at startup, with no `malloc`/`new` in the processing loop
